# ShowerCore

An add-on for [Hot Bath](https://crabmods.com/mods/hotbath), with core-powered showers, area buffs, two-seat bathtubs and a rubber duck.

[Download: CurseForge](https://www.curseforge.com/minecraft/mc-mods/showercore) · [Modrinth](https://modrinth.com/mod/showercore) · [Full guide](https://crabmods.com/mods/showercore) · [Trailer](https://www.youtube.com/watch?v=iOpgwCFBCWI)

## Features

- Six shower cores with different buffs. Shower buffs build up to two minutes.
- Place cores in conduit-style frames to give players area buffs.
- Fill bathtubs with Hot Bath fluids, share a bath and customize the tub material.
- Compact and rain shower heads, clawfoot tubs and a floating rubber duck.

## Install and start

Install matching ShowerCore and Hot Bath builds on the server and every client. Current lanes: Forge 1.20.1 / Java 17 and NeoForge 1.21.1 / Java 21.

Fit a core into a shower head, then empty-hand right-click to toggle it. Fill a bathtub with a fluid container and empty-hand right-click a seat to sit. Tub effects differ from shower effects.

Hot Bath 的扩展，提供核心驱动的淋浴、范围增益、双人浴缸和橡皮鸭。

- 六种淋浴核心，各有增益，持续时间可累积至两分钟。
